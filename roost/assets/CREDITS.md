# Third-party assets

## `raven.svg` and its rasterized variants

**Raven** by **Lorc**, from [game-icons.net](https://game-icons.net/).
Licensed under [Creative Commons Attribution 3.0 Unported (CC BY 3.0)](https://creativecommons.org/licenses/by/3.0/).

Files derived from it, all generated by `tools/build-icons.sh`:

- `raven.png`, `raven@2x.png` — full-colour rasterizations
- `raven-template.png`, `raven-template@2x.png` — the same paths with the fill
  forced to black, so macOS's template rendering (which keeps only the alpha
  channel) has the full silhouette to tint

CC BY 3.0 permits redistribution, including commercially and in modified form,
**and requires that credit be given**. Recolouring the fill and rasterizing to
PNG are modifications; the attribution above covers the original and every
derivative listed.

This is a licence obligation, not a courtesy. If the raven art is removed from
this repository, remove this section with it; if another icon is added, credit it
here before shipping.

## `roost.svg` and its rasterized variants

Roost's own mark. Copyright 2026 Ron Scott-Adams, licensed under the same
Apache-2.0 terms as the rest of this repository — see [`../../LICENSE`](../../LICENSE).

The mark is a compact raven at rest in a warm nest: a visual for a shared status
home, rather than the app-grid glyph that this option formerly used. Its checked-in
rasterizations are `roost.png`, `roost@2x.png`, `roost-template.png`, and
`roost-template@2x.png`, generated by `tools/build-icons.sh`.
